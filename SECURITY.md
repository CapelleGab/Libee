# Security Policy

Libee runs package manager commands on the user's machine, so security is a core concern.

## Reporting a vulnerability

**Please do not open a public issue.** Use
[GitHub private security advisories](https://github.com/CapelleGab/Libee/security/advisories/new) instead.

You will get a response within 7 days.

## Supported versions

Only the latest release receives security fixes.
